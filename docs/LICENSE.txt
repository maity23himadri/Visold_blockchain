NON-CUSTODIAL SOFTWARE
  Visold (VSD) is non-custodial software.  No developer, company, or central
  authority holds or controls user funds.  All private keys are generated and
  stored exclusively on the user's own device.  If a user loses their Secret
  Key and account.json file, funds cannot be recovered by any party.

NO WARRANTY OF FINANCIAL RETURNS
  This software is a fully functional, production-grade decentralised protocol
  implementation operating on a live network with real peer-to-peer consensus.
  It does not constitute financial advice, a security offering, or a promise of
  any return on investment.  Users participate at their own risk and are solely
  responsible for the safekeeping of their private keys and any funds held
  within the network.

DECENTRALISED NETWORK
  The Visold network is governed entirely by on-chain consensus (75 % miner
  signal threshold, BFT finality).  No individual — including the original
  authors — holds a master key, network pause capability, or the ability to
  freeze user accounts.  All rule changes require community governance.
